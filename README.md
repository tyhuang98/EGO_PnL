# EGO_PnL-release

Implementation of the paper:

[Efficient and Globally Optimal Camera Orientation Estimation with Line Correspondences] (Accepted to IEEE-RAL 2024).

## Usage
Unzip the functions.zip and then directly run the test_outlier.m to test.
